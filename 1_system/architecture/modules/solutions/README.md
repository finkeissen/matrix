# Solutions Track

## Objective
Generate structured `SolutionApproach` artifacts and link them to atomic problems.

This track is separate from Problems Track to prevent:
- solutions without well-defined problems,
- accidental semantic upgrades.

## Entry conditions
A problem is eligible for solution generation if it has at least:
- one Symptom
- and either a CauseHypothesis OR an explicit "cause_unknown" marker.

## Files
- `solution_seed.md`
- `solution_refine.md`
- `solution_quality.md`
- `schemas.md`
