# work

The `work/` directory contains **non-normative working material**.

It is the **explicitly permitted space for incompleteness, exploration, provisional structure,
and epistemic risk**.

Nothing in `work/` represents the Matrix state.
Nothing in `work/` is authoritative.
Nothing in `work/` is required to be stable, consistent, or complete.

`work/` exists so that unfinished thinking does **not** contaminate `domains/`.

---

## Role of `work/` in the Repository

This repository distinguishes strictly between:

- **work** — exploratory, preparatory, provisional material  
- **domains** — the current, referencable epistemic state  
- **runs** — executable, auditable transitions  
- **exports** — frozen snapshots  

`work/` is **not** a staging area for automatic promotion.

There is **no fixed rule** governing when or how material moves
from `work/` into `domains/`.

Any such transition must be made explicit through:
- a documented decision, and
- an MMS run recorded under `runs/`.

---

## Project Phases (Conceptual)

This repository publicly represents **Phase 0 and later only**.

Earlier phases (raw exploration and pre-Matrix work)
exist but are intentionally **not published as Matrix content**.

They are represented through:
- explicit absence,
- documentation,
- and separation.

Phase 0 begins with:
- explicit separation of artifacts and facts
- domain-defined stress tests
- run-based structural validation

## Directory Structure

work/
raw/
pre-matrix/
exploration/
production/


Each subdirectory has a **distinct epistemic role**.
They are **not chronological guarantees** and **not maturity labels**.

---

## `work/raw/` — Raw Materials (Not Public)

This directory represents **raw materials used during early exploration
and data collection**.

These materials include:
- unstructured inputs
- exploratory outputs
- large intermediate artifacts
- commercially or legally sensitive sources
- prompts, partial results, and drafts

Raw materials are **intentionally excluded**
from the public Matrix state.

Their absence from `domains/` is **by design**, not by omission.

Nothing in `work/raw/` is expected to be:
- structured
- normalized
- stable
- or reusable

---

## `work/pre-matrix/` — Pre-Matrix Phase (Not Public)

This directory represents **early structural attempts**
that precede the Matrix architecture.

This phase involved:
- pipeline-oriented thinking
- implicit factual assumptions
- incomplete domain separation
- early extraction and mapping attempts

These materials are retained for:
- historical comparison
- methodological learning
- failure analysis

They are **not part of the Matrix**
and must not be interpreted as such.

Only the **post–Phase 0** structure
is represented in `domains/`.

---

## `work/exploration/` — Exploratory Work

This directory contains **active exploratory material**, such as:
- alternative structural hypotheses
- competing domain cuts
- provisional mappings
- unresolved conflicts
- test extractions

Exploration material:
- may contradict itself
- may be abandoned
- may never transition to `domains/`

Exploration is **explicitly encouraged**
and **explicitly non-binding**.

---

## `work/production/` — Pre-Export Preparation

This directory contains **preparatory work**
for potential exports or snapshots.

Typical contents include:
- consolidation attempts
- validation experiments
- review notes
- candidate selections for export

Material in `work/production/` is **still not authoritative**.

Authority, such as it exists at all,
emerges only through:
- explicit runs
- documented constraints
- and published exports

---

## Explicit Non-Guarantees

The presence of material in `work/` does **not** imply:
- correctness
- relevance
- future inclusion
- endorsement
- or survival

Deletion, abandonment, and contradiction
are all acceptable outcomes.

---

## Summary

> **`work/` is where uncertainty is allowed to exist without consequence.**

It protects the Matrix
by ensuring that unfinished reasoning
never masquerades as structured knowledge.
