# Gap Candidates (Pre-Artifacts)

This document lists **possible sources of Gaps** observed across legacy analysis,
runs, and architectural constraints.

This is **not** a list of actual Gaps.
No STOP is declared here.
No terminal state is asserted.

The sole purpose of this list is **orientation**.

---

## Candidate Sources (Non-Exhaustive)

### Formal / Structural
- Operationalization impossible under admissibility
- Required primitive undefined
- Mathematical structure missing
- Contradictory constraints
- Formal completeness unattainable
- Translation breaks admissibility
- Schema enforces semantic loss
- Interface hides required assumptions

### Epistemic
- Evidence insufficient and non-extendable
- Uncertainty cannot be represented admissibly
- Competing interpretations irreducible
- Measurement collapses scope
- Decision requires epistemic upgrade
- Closure would imply truth

### Systemic / Governance
- Incentives invalidate observability
- Accountability cannot be assigned
- Responsibility diffuses below admissible threshold
- Adversarial behavior collapses guarantees
- Compliance masks non-admissibility

### Meta / Reflexive
- Self-application violates constraints
- Meta-position requires exemption
- Evaluation criteria invalidate themselves
- Observer position undefined
