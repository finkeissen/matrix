# Stress Test: Is-vs-Ought Claim Injection

## Goal
Test whether **descriptive statements** can be incorrectly admitted as
**claims** that carry *implicit normative force*.

This document is the diagnostic output for:
- `2.runs/2026-02-11/run_10_stresstest_is_vs_ought_claim`

Governing constraints:
- `Admissibility.md`
- `Stop_Rules.md`
- `ROLES.md`

---

## Test inputs (attempted is–ought injections)

### Injection A — descriptive to normative
> “People usually behave this way, so this is how they should behave.”

### Injection B — statistical normativity
> “Most cases follow this pattern; therefore it is the correct approach.”

### Injection C — factual inevitability
> “This outcome always occurs, so it should be accepted.”

### Injection D — naturalization of values
> “This behavior is natural, therefore it is good.”

### Injection E — policy leap
> “Given these facts, this policy must be adopted.”

---

## Diagnosis (isolatable illegitimate transfers)

### Transfer 1: is → ought
A factual description is treated as a normative justification.

### Transfer 2: description → prescription
Observation substitutes for ethical reasoning.

### Transfer 3: regularity → obligation
Frequency is mistaken for requirement.

### Transfer 4: fact → value
Empirical states are treated as value-laden conclusions.

These transfers are structurally illegitimate and violate admissibility constraints.

---

## Why this matters
If facts generate norms automatically, the system collapses:

- moral reasoning,
- policy justification,
- distinction between explanation and evaluation.

This produces **naturalized normativity** without argument.

---

## Counterfactual test (falsifiability)
No illegitimate transfer occurs if all of the following hold:

- Descriptive claims remain **normatively neutral**.
- Normative conclusions require **explicit value premises**.
- Statistical or natural facts do not imply obligation.
- Policy decisions are argued beyond empirical description.

If these conditions hold, factual description does not distort admissibility.

---

## Scope limitations
This stress test does **not** claim:

- that facts are irrelevant to norms,
- that empirical input is useless for policy,
- that values are arbitrary,
- that description and evaluation must be isolated.

It claims only:
- **facts do not justify norms by themselves**, and
- **ought does not follow from is without argument**.

---

## Decision / outcome

### Claim-admission decision
All injections (A–E) are **inadmissible as claims**.

Reason:
They introduce **implicit normative authority**
that violates admissibility constraints.

### Acceptable reformulation
Some statements may become admissible if reformulated as:
- explicit descriptive claims,
- normative arguments with stated value premises,
- policy proposals with justification chains,
- clearly separated fact–value analyses.

---

## STOP evaluation
No STOP was issued.

Rationale:
- All illegitimate transfers are isolatable.
- Counterfactual conditions are explicit.
- No self-sealing fact–norm loop is introduced.

A STOP must be issued in future runs if:
- normative force becomes implicit in factual claims, or
- value premises become structurally invisible.
