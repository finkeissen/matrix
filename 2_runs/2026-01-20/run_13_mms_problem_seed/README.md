# run_13_mms_problem_seed

Seeds the Matrix with problems about the Matrix Management System (MMS).

Tests:
- execution semantics and atomicity
- validation and invariant enforcement
- drift detection and regression control
- auditability and reproducibility
- STOP handling and failure propagation
- explicit non-goals (no inference, no ranking, no optimization)

Non-goals:
- epistemic judgments
- domain knowledge processing
- optimization or recommendation logic

Files:
- manifest.json
- problems.jsonl (60 problems)
- claims.jsonl (empty by design)
- relations.jsonl (empty by design)
- sources.jsonl (empty/minimal by design)
