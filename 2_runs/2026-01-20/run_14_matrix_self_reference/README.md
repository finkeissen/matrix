# run_14_matrix_self_reference

Seeds the Matrix with self-referential problems.

Tests:
- Matrix as epistemic subject
- representation of its own assumptions and limits
- prevention of implicit authority
- misinterpretation and misuse risks
- scaling and aggregation effects
- governance and termination criteria

Non-goals:
- resolving self-referential paradoxes
- claiming epistemic completeness
- providing guarantees about correct use

Files:
- manifest.json
- problems.jsonl (50 problems)
- claims.jsonl (empty by design)
- relations.jsonl (empty by design)
- sources.jsonl (internal/minimal)
