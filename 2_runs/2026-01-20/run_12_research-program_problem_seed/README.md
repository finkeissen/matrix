# run_12_research_program_problem_seed

Seeds the Matrix with meta-level problems about the research-program layer.

Tests:
- admissibility and boundary setting
- prevention of authority transfer
- conflict representation policies
- uncertainty semantics
- temporal revision vs contradiction
- governance and STOP documentation
- schema evolution and migration traceability
- self-reference and representing Matrix failure modes

Non-goals:
- external domain claims
- implementation details of MMS
- resolution of philosophical disputes

Files:
- manifest.json
- problems.jsonl (60 problems)
- claims.jsonl (empty by design)
- relations.jsonl (empty by design)
- sources.jsonl (empty/minimal by design)
