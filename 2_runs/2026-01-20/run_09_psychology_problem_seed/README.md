# run_09_psychology_problem_seed

Seeds the Matrix with psychology problems to test:
- construct and measurement validity
- competing theoretical models
- replication limits and methodological uncertainty
- normative pressure without action guidance
- context and cultural dependence

## Non-goals
- diagnosis or therapy
- treatment recommendations
- individual assessment

## Files
- manifest.json
- problems.jsonl (120 problems)
- claims.jsonl (empty by design)
- relations.jsonl (empty by design)
- sources.jsonl (empty/minimal by design)
